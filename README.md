# deepseek · 情绪感知桌面宠物

> 通过 Mac 摄像头实时识别你的情绪，用桌面宠物陪伴、安抚你。
> **隐私承诺：全部推理在本机离线完成，摄像头画面绝不上传。**

## 一、项目概述

一个运行在 macOS 上的桌面应用：

1. 调用 Mac 内置摄像头，实时捕捉面部画面；
2. 在本地完成人脸检测与表情识别，推断当前情绪（开心 / 难过 / 生气 / 恐惧 / 惊讶 / 厌恶 / 平静）；
3. 桌面上出现一只透明窗口的宠物，根据你的情绪做出相应行为 —— 难过时拥抱你、生气时引导深呼吸、开心时跳舞庆祝；
4. 可选：用 macOS 语音合成（TTS）让宠物开口说话安慰你。

## 二、总体架构

```
┌────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  摄像头采集  │──▶│  人脸检测      │──▶│  表情识别      │──▶│  情绪平滑      │──▶│  宠物行为引擎  │
│  OpenCV    │   │  MediaPipe   │   │  FER2013 CNN │   │  EMA + 窗口   │   │  状态机       │
└────────────┘   └──────────────┘   └──────────────┘   └──────────────┘   └──────┬───────┘
                                                                                 │
                                                      ┌──────────────────────────┘
                                                      ▼
                                        ┌──────────────────────────┐
                                        │  宠物渲染层 (PyQt6)        │
                                        │  透明无边框置顶窗口          │
                                        │  帧动画 / 气泡文案 / TTS    │
                                        └──────────────────────────┘
```

数据流：**摄像头(30fps) → 人脸裁剪 → 表情分类(10~20fps) → 情绪平滑(每 2~3 秒输出主导情绪) → 宠物行为切换**。

## 三、技术选型

| 环节 | 选型 | 理由 |
|---|---|---|
| 摄像头采集 | OpenCV `VideoCapture(0)` | 成熟稳定，macOS 首次运行弹权限框 |
| 人脸检测 | MediaPipe FaceMesh | 实时 ~30fps，轻量，可同时取面部关键点 |
| 表情识别 | FER2013 轻量 CNN（ONNX 部署） | 7 类情绪，本地 CPU 推理 10~20fps，无 GPU 依赖 |
| 情绪平滑 | 指数移动平均(EMA) + 滑动窗口 | 防止表情抖动导致宠物行为反复横跳 |
| 桌面宠物窗口 | PyQt6 无边框透明窗口 | 透明背景、置顶、可鼠标穿透，天然适合桌面宠物 |
| 宠物动画 | 帧序列动画（QTimer 驱动）| 实现简单，可替换为 Lottie 提升质感 |
| 语音安抚 | macOS TTS（`say` / pyttsx3）| 中文语音无需额外模型，系统自带 |
| 打包分发 | py2app（可选） | 打包成 .app，可开机自启 |

**备选方案对比：**

- **Swift + Vision 框架**：能拿 smile 等面部特征，但情绪分类需用 Create ML 自训模型，周期长，留作二期优化。
- **Electron + TensorFlow.js (face-api.js)**：浏览器内表情识别方便，但应用体积大、内存高，桌面宠物场景偏重。
- 本方案 **Python 最快出原型**，后续可平滑迁移到 Swift 打磨。

## 四、情绪 → 宠物行为映射

| 情绪 | 宠物行为 | 气泡文案（示例） | TTS 语音（示例） |
|---|---|---|---|
| `neutral` 平静 | 日常 idle：打盹、伸懒腰、眨眼 | — | — |
| `happy` 开心 | 跳舞、撒花、蹦跳庆祝 | 「哇，你今天超棒！」 | 「看到你开心，我也好开心呀！」 |
| `sad` 难过 | 靠近屏幕中央、拥抱动画、贴贴 | 「别难过，我一直都在呀」 | 「别难过，我会一直陪着你，抱抱～」 |
| `angry` 生气 | 安抚动画、吹气引导 | 「深呼吸，我陪你慢慢把气吐出来」 | 「深呼吸一下，我陪你把坏情绪都吐掉」 |
| `anxious` 焦虑 | 陪你数呼吸、放轻提示 | 「跟着我，一、二、三……慢慢来」 | 「跟着我一起深呼吸，你做得很好」 |
| `fear` 恐惧 | 靠近守护、陪伴动画 | 「别怕，有我在」 | 「别怕，我一直都在你身边」 |
| `surprise` 惊讶 | 好奇探头、歪头 | 「咦？发生什么啦？」 | 「咦？是什么让你这么惊讶呀？」 |
| `disgust` 厌恶 | 皱眉歪头、关切 | 「这个让你不舒服吗？」 | 「是不是有让你不舒服的东西呀？」 |

> 情绪平滑策略：对每一帧识别结果做 EMA 平滑，每 2~3 秒取窗口内主导情绪；连续 2 个窗口相同才切换宠物行为，避免抖动。

## 六·五、当前进度与运行方式

### M1 已完成 ✅

- `emotion/capture.py` — macOS 优先原生 AVFoundation 采集（OpenCV 对 FaceTime 内置相机不可靠），失败回退 OpenCV
- `emotion/native_capture.py` — pyobjc 原生采集（强制 BGRA 输出）
- `emotion/detector.py` — YuNet 人脸检测 + FER+ 表情识别（8 类情绪）
- `emotion/smoother.py` — EMA 情绪平滑（抑制抖动）
- `main.py` — 终端实时情绪 Demo
- 模型已就位：`emotion/models/emotion-ferplus-8.onnx` + `face_detection_yunet_2023mar.onnx`

**运行 M1 Demo：**

```bash
.venv/bin/python main.py            # 带调试窗口（人脸框 + 情绪标签），按 q 退出
.venv/bin/python main.py --headless # 纯终端输出
```

### M2 已完成 ✅

- `pet/pet_engine.py` — 行为状态机（6 种行为 + 切换防抖）
- `pet/pet_widget.py` — QPainter 手绘动画宠物（呼吸/蹦跳/眼泪/蒸汽/zzz 等） + 气泡文案
- `pet/main_window.py` — 无边框透明置顶窗口，可拖拽
- `pet/__main__.py` — 入口

**运行 M2 桌面宠物：**

```bash
.venv/bin/python -m pet
# 按键: 1~6 切换行为(日常/开心/难过/生气/惊讶/困困), 空格或双击说话, Esc 退出
```

### 安装依赖

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

> 本机 pip 默认镜像（清华）不可用时，可加 `--index-url https://mirrors.aliyun.com/pypi/simple/`。

## 七、macOS 权限与隐私

- **摄像头权限**：首次运行弹出系统授权框，需在「系统设置 → 隐私与安全性 → 摄像头」允许。注意：若从终端运行，权限挂在 Terminal 上；打包成 .app 后权限挂在 App 上。
- **不申请屏幕录制权限**：只读摄像头，不做屏幕采集。
- **全程离线**：模型文件本地加载，画面不出本机，符合隐私优先原则。

## 八、环境要求

- macOS 12+（TTS 中文语音需系统自带「婷婷/Ting-Ting」等中文音色）
